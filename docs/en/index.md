# autocraw documentation

autocraw (`@zhadev/autocraw`) is a site intelligence crawler for Node.js 22+. It turns web pages into clean Markdown, maps and crawls sites, and explains how a site is built: tech stack, rendering strategy, hydration traps, URL patterns, pagination, search, filters, media sources and more. It ships as a CLI, a TypeScript library and a local REST API.
