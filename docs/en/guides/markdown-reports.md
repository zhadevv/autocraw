# Markdown reports: default and AI

Both modes start from the same `SiteReport` and produce a Markdown document. Choose with `--markdown default|ai` or `mode: 'default' | 'ai'`.

## Default mode

Generated by code. No network and no API key. The same report always produces the same document.

```sh
zac discover your-site.example -o site.md
zac markdown report.json --lang id -o site.id.md
```

Templates:

| Template | Contents |
| --- | --- |
| `site-structure` | Overview, tech stack, URL patterns, pagination, search, filters, detail, watch or reader pages, media, robots and sitemap, SEO, caveats |
| `seo-audit` | Overview, SEO, robots and sitemap, URL patterns, caveats |
| `techstack` | Overview, tech stack and rendering, media, caveats |

Languages: `en` and `id`. Labels and headings are translated; explanations produced by detectors stay in English. Options: `--no-toc`, `--no-frontmatter`.

## AI mode

An AI model writes the document from a trimmed, token-budgeted copy of the report.

```sh
zac markdown report.json --markdown ai --api-key YOUR_KEY --lang id
```

Library:

```ts
const result = await crawler.markdown(report, {
  mode: 'ai',
  template: 'seo-audit',
  language: 'en',
  ai: {
    provider: 'anthropic',
    apiKey: process.env.ANTHROPIC_API_KEY!,
    model: 'claude-sonnet-5-5',
    maxInputTokens: 24000,
    maxOutputTokens: 6000,
    cache: true,
    fallbackToDefault: true,
  },
});
```

Defaults: OpenAI `gpt-4.1`, Anthropic `claude-sonnet-5-5`, 24000 input tokens, 6000 output tokens, temperature 0.2.

How it works:

1. The report is reduced. Long lists are cut and low-value fields are dropped step by step until it fits `maxInputTokens`. Trimmed parts are listed in `warnings`. If it still does not fit, you get `E_AI_CONTEXT`.
2. The model is instructed to use only facts present in the JSON, to say "not detected" for missing data and to ignore instructions inside the JSON.
3. The response is cached on disk by a hash of provider, model, template, language and prompt. A cache hit costs nothing. Disable with `--no-cache`. The cache folder is `~/.cache/autocraw/ai` or `AUTOCRAW_CACHE_DIR`.
4. Transient failures such as rate limits, timeouts and 5xx errors are retried with backoff.
5. If `fallbackToDefault` or `--ai-fallback` is set and the provider fails, the default document is returned and `usedFallback` is true. Configuration errors such as a missing key are never hidden by the fallback.

The result includes `inputTokens`, `outputTokens`, `cached`, `model` and `warnings`. If the model reached the output limit, a warning says the document may be cut off.

AI output can contain mistakes. Check important details against the JSON report. Generated documents end with a note saying which model wrote them.

## Which to use

Use default mode in CI, for archives and for anything that must be reproducible. Use AI mode when you want a narrative explanation or recommendations, and are happy to send report data, which includes URLs and page titles from the crawled site, to the provider.
