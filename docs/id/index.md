# Dokumentasi autocraw

autocraw (`@zhadev/autocraw`, perintah CLI: `zac`) adalah site intelligence crawler untuk Node.js 22+. Ia mengubah halaman web jadi Markdown yang rapi, memetakan dan meng-crawl situs, mengekstrak data terstruktur dengan AI, dan menjelaskan bagaimana sebuah situs dibangun: tech stack, strategi rendering, hydration trap, pola URL, pagination, search, filter, dan sumber media. Tersedia sebagai CLI, library TypeScript, dan REST API lokal.
